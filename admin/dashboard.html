Password changes

The admin password is not stored in the browser. To change it, regenerate the encrypted admin payload with the documented build command and redeploy the site.

This password gates the admin UI only, not the database.

The encrypted payload can be downloaded and attacked offline, so use a strong unique password. Note: Realtime Database writes are open to any signed-in visitor by owner decision, so the password does not protect the data itself.
